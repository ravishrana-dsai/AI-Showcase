## Product

### Player Rating ([Company] Rating)

A Video AI-powered scientific skill score for every player, generated from raw match video using in-house Vision Language Models and proprietary ML.

**Three pillars:**
- **TECH (Technical):** Winner:Error Balance, Overhead Proficiency, Shot Selection
- **TACT (Tactical):** Net Control Time, First-Phase Initiative, Side-Role Efficiency
- **PHY (Physical):** Movement Economy, Time-to-Net, Reactive Time, Acceleration

### Four Product Capabilities

1. **Player Rating:** Scientific skill score (objective, measurable, credible)
2. **Game Analysis and Insights:** Shot-by-shot breakdowns, rally analysis, movement heatmaps
3. **Coaching:** Structured improvement paths built from real match data
4. **Content and Matchmaking:** Auto-generated highlights, fair brackets, skill-matched opponents

### Technology Stats

- 5M+ structured data points per match
- Model stack: 20+ Classical + 10+ Deep Learning + 50+ fine-tuned VLMs
- 16x accuracy advantage over generic AI (80% SkillScore accuracy via DreamLens vs less than 5% raw Gemini)
- 95%+ consistency vs less than 25% for generic LLMs
- 10x lower compute cost

### Data Assets

- 20,000+ hours of video
- 10,000+ matches
- 3M+ annotated images
- $200M+ dataset replacement cost

### Platform Stack

- **Mobile App:** React Native
- **Backend:** Java Spring Boot on AWS
- **AI/ML:** GCP Cloud Functions
- **Internal Ops:** Web-based panel

### Problem We Solve

Amateur players have no accurate, objective way to know their skill level. Existing ratings are self-assessed or based on basic win/loss records. Without a skill signal, matchmaking is poor, improvement slows, and the player journey breaks down.
