# PRD to Feature

> Paste a Product Requirements Document and get back a design spec plus production-ready Next.js UI and API code, generated by Gemini in seconds.

## AI Stack

| Component | Technology |
|---|---|
| PRD parsing + design spec generation | Google Gemini 2.5 Pro |
| Next.js code generation | Google Gemini 2.5 Pro |
| Export | JSZip (downloadable project ZIP) |

## Key Achievements

- Three-stage AI pipeline: (1) parse PRD to extract requirements, (2) generate design spec with component breakdown, (3) generate Next.js App Router code for UI and API routes
- Full project export: generated code is bundled into a downloadable ZIP ready to drop into a Next.js project
- Supports PRD upload (`.md` or `.txt`) or direct paste
- Playwright test suite validates the generation pipeline end-to-end
- Multi-server setup (ports 3002 and 3003) for running two instances in parallel during testing

## Tech Stack

- **Framework:** Next.js 14 (App Router), TypeScript, Tailwind CSS
- **AI:** Google Gemini API (`@google/genai`)
- **Export:** JSZip
- **Testing:** Playwright

## How to Run

```bash
npm install
cp .env.local.example .env.local
# Add GEMINI_API_KEY (from https://aistudio.google.com/apikey)
npm run dev
```

Open http://localhost:3000. Paste or upload a PRD, click **Generate feature**, and download the ZIP.
