Claude Usage Tracker — Setup

Follow these steps to route each Claude product through the local proxy.

1

Claude Code

Add to ~/.zshrc or ~/.bash_profile, then restart your terminal:

export ANTHROPIC_BASE_URL=http://127.0.0.1:9876
export HTTP_PROXY=http://127.0.0.1:9876
export HTTPS_PROXY=http://127.0.0.1:9876
export NODE_TLS_REJECT_UNAUTHORIZED=0
2

Claude Desktop & Cowork

Run these two commands in Terminal (replace "Wi-Fi" with your interface name if different):

networksetup -setwebproxy Wi-Fi 127.0.0.1 9876
networksetup -setsecurewebproxy Wi-Fi 127.0.0.1 9876

To disable later: networksetup -setwebproxystate Wi-Fi off

3

Claude.ai in Browser

Install SwitchyOmega for Chrome, create a proxy profile: HTTP proxy at 127.0.0.1 port 9876. Enable when using Claude.ai.

4

For Full HTTPS Decryption (optional)

Install mitmproxy for complete token counts from encrypted traffic:

pip install mitmproxy
mitmproxy --listen-port 9876 --ssl-insecure
⚠️ The built-in proxy captures connection metadata and HTTP traffic. Full HTTPS decryption requires mitmproxy and trusting its CA certificate in Keychain Access.
