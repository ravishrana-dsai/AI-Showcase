# 05. Visual Identity

[Company]'s visual identity should feel like precision in motion. The brand lives at the intersection of sport (energy, movement, competition) and intelligence (data, clarity, structure). Neither should dominate. Both should be felt.

This section covers direction and principles. Specific production assets (logo files, type files, color swatches) are maintained separately in the design system.

---

## Visual Personality

The visual identity answers one question: **what does player intelligence look like?**

It looks like:
- A heatmap of a player's court movement
- A Player Rating badge that feels like an achievement
- A shot trajectory plotted on a court diagram
- Data that is beautiful enough to share

It does not look like:
- Generic sports photography with lens flares
- Dark moody fitness aesthetics
- Overly corporate charts and tables
- Clip-art padel racquets

## Color Direction

### Primary Palette

[Company]'s primary palette is built around three roles: **Action, Ground, and Signal.**

**Action Color: Electric Lime / Performance Green**
The brand's primary accent. High-contrast, energetic, instantly visible on dark backgrounds. This is the color of the Player Rating badge, active states, key data points, and primary CTAs.
- Reference direction: #C8F53A range (adjust to final production spec)
- Feel: precision, energy, forward movement
- Usage: Player Rating score displays, highlights, primary buttons, key callouts

**Ground Color: Deep Court / Near-Black**
The background that makes everything else pop. Not pure black (too harsh, too generic). A dark tone with a hint of depth, like a padel court at night under floodlights.
- Reference direction: #0F0F14 to #1A1A24 range
- Feel: premium, focused, serious intelligence
- Usage: app backgrounds, hero sections, video overlays

**Neutral: Chalk White / Off-White**
Clean, readable, never clinical. Used for body text, secondary elements, and white-space balance.
- Reference direction: #F4F4F0 range
- Feel: clarity, accessibility, balance

### Secondary Palette

Supporting colors for data visualization and UI depth:

| Role | Direction | Usage |
|---|---|---|
| Data Highlight 1 | Vivid Cyan (#38D4E8 range) | Tactical metrics, net play data |
| Data Highlight 2 | Warm Amber (#F5A623 range) | Physical metrics, movement data |
| Data Highlight 3 | Soft Coral (#F26B5B range) | Error data, areas for improvement |
| Success State | Lime (primary action color) | Improvements, positive trends |
| Neutral Surface | #2A2A35 range | Cards, containers, secondary backgrounds |

### Color Rules

1. The lime/performance green is reserved for brand. Do not use it generically or decoratively.
2. Data visualizations should use the defined palette only. Do not introduce new colors per visualization.
3. Accessibility minimum: 4.5:1 contrast ratio for all body text. 3:1 for large headings.
4. The deep court dark background is the dominant ground in digital. Light mode is a secondary state.

## Typography

### Type Philosophy

Data-rich interfaces require type that is precise, legible at small sizes, and carries weight at display sizes. [Company] uses two typefaces:

**Display / Headline: A geometric sans-serif with character**
- Direction: Something in the Neue Haas Grotesk, Aktiv Grotesk, or similar geometric/grotesque family
- Feel: modern, confident, structured
- Usage: Player Rating score display, headlines, campaign titles, large callouts
- Key characteristic: Should look strong in bold weight at 12pt and still feel premium at 80pt

**Body / UI: A high-legibility variable sans-serif**
- Direction: Something in the Inter, DM Sans, or similar utility-first category
- Feel: neutral, readable, scales beautifully
- Usage: all body copy, UI labels, data labels, navigation, captions
- Key characteristic: Must perform at 11pt in data-dense contexts without losing clarity

### Type Scale

| Use | Weight | Size Range |
|---|---|---|
| Player Rating Score Display | Black / 900 | 64pt to 96pt |
| Hero Headlines | Bold / 700 | 32pt to 52pt |
| Section Headlines | Semibold / 600 | 20pt to 28pt |
| Body Copy | Regular / 400 | 14pt to 16pt |
| Data Labels | Medium / 500 | 10pt to 13pt |
| Captions / Fine Print | Regular / 400 | 10pt to 12pt |

### Type Rules

1. Headlines are set in display face. Body is set in UI face. Never swap.
2. All caps usage: only for metric labels and category names (TECH, TACT, PHY). Not for headlines or body copy.
3. Numeric data (Player Rating scores, percentages, stats) always uses the display face, regardless of size.
4. Line height for body copy: 1.5x. Tight tracking for display: -0.02em.

## Logo Direction

### Principles

The [Company] logo is a wordmark-first identity. It should communicate precision and movement in a form that works across the range from a 16px app icon to a stadium banner.

**Wordmark:**
- "[Company]" set in the display typeface
- Tight tracking, high contrast
- Should feel modern and sport-forward, not tech-corporate

**Symbol / Mark:**
- A standalone icon that works independently of the wordmark
- Direction: something derived from court geometry, trajectory, or the concept of a score/rating
- Must work at 16px for app icon and 200px for profile use without loss of clarity
- Should not be a racquet, ball, or court literally. Abstract the concept.

### Logo Lockups

| Version | Usage |
|---|---|
| Primary (dark bg) | Lime wordmark on deep court background. Default for digital. |
| Primary (light bg) | Dark wordmark on white/off-white. Print and light UI contexts. |
| Monochrome dark | Black wordmark. B&W documents, embossing. |
| Monochrome light | White wordmark. Dark apparel, reversed contexts. |
| Symbol only | App icons, favicons, social avatars, contexts where wordmark doesn't fit. |

### Logo Rules

1. Never stretch or distort the logo.
2. Clear space minimum: equal to the height of the letter "D" in Dream on all sides.
3. Minimum size: 80px wide for digital, 20mm for print.
4. Never place the logo on a busy photographic background without an overlay or clear field.
5. Never recreate the logo in a different typeface.

## Imagery and Photography

### Approach

[Company] imagery has one job: **make the player feel seen.**

Not glamorised. Not generic stock. Real players at real courts, in moments of competition, focus, and improvement.

### Shot Types

**Hero: The Focus Moment**
A player mid-point. The shot about to happen. Court background. Authentic. Not posed. High energy, not high production.

**Data Overlay: The Intelligence Layer**
Game photography with Player Rating metrics, shot paths, or heatmaps overlaid. This is the [Company] visual signature. Data on top of the real moment. Intelligence meeting sport.

**Community: The Social Game**
Four players at the net. Post-match. Relaxed. This is why they play. Use to humanise the brand and acknowledge that padel is a social sport.

**Achievement: The Score Reveal**
Close-up on the Player Rating badge or score. This is a reward visual. Use for sign-up completion, post-match notifications, and milestone moments.

### Photography Rules

1. No lens flares. No exaggerated color grading.
2. Real padel courts, not studio setups.
3. Diverse players by age, gender, and background. The game is for everyone.
4. Action should look real, not staged. If it looks like a stock photo, it is not [Company].
5. When overlaying data, use the brand data palette. Never random colors.

### Video Direction

**Highlights:** Fast-paced, data-overlaid, 15 to 60 seconds. Player Rating badge reveal at the end.
**Brand films:** Sport-first storytelling. Data and AI are the behind-the-scenes hero, not the front-stage presenter.
**Explainers:** Screen-recording style for product features. Clean, fast, no unnecessary animation.

## Data Visualization Style

Data is a core visual element in the [Company] brand. It should be:

**Beautiful and readable simultaneously.** Never sacrifice clarity for aesthetics.
**Consistent.** Every metric category has its own color (TECH = cyan, TACT = amber, PHY = coral, Overall Player Rating = lime).
**Minimal.** Remove every axis label, gridline, and legend entry that doesn't add information.
**Branded.** Court diagrams use brand colors. Heatmaps use brand palette. Nothing looks like it came out of Excel.

### Standard Visual Components

| Component | Description |
|---|---|
| Player Rating Badge | The primary achievement display. Large score, category ring, player name. Full brand treatment. |
| Radar Chart | TECH / TACT / PHY breakdown. Three-axis. Brand colors per axis. |
| Court Heatmap | Movement or shot frequency overlaid on court outline. Gradient using brand palette. |
| Shot Trajectory | Ball path overlaid on court. Colored by shot type or outcome. |
| Timeline Bar | Rally and match timeline. Color-coded by point outcome. |
| Progress Trend | Line chart showing Player Rating over time. Single color, minimal chrome. |
